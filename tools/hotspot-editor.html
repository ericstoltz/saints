Hotspot editor: mark the saints' faces on a wall photo

Choose a wall photo to start.

1. Photo

Use a sharp, straight-on photo of one wall section. Save the same file into app/img/mural/<wall name>.jpg.

2. Faces
  1. Click a face to add a circle.
  2. Pick the saint for the selected circle.
  3. Drag to move. Use the slider to resize. Delete removes it.
3. Save

Copy this wall's entry into the walls list in app/data/mural.js, replacing the old entry with the same id. You can also paste an existing entry here and click Load to edit it.
